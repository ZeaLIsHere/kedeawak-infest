Rincian pelaksanaan T5.11 sampai T5.14 dan T5.16 di `PLAN.md`, bukan daftar
fitur baru. User menyetujui penggantian Fonnte dengan Twilio Sandbox, termasuk

teks lalu orderan. Groq Whisper dipilih oleh tim implementasi untuk transkripsi,

## Konfigurasi dan batas demo

Lihat `README.md` untuk contoh lengkap `.env.local`, migrasi, peringatan seed,
Node 24, dan pengaturan Sandbox. Akses template env diblokir pengaturan privasi:
tidak dibaca dengan cara lain, tidak dilewati, dan tidak ada berkas `.env` yang
ditulis dalam tugas dokumentasi ini. Cipher saat ini mengharuskan kunci hex
64 karakter; output base64 `randomBytes(32)` harus dikonversi ke hex dahulu.
`PGLITE_DATA_DIR=.pglite/data` adalah pilihan eksplisit, bukan nilai bawaan kode.
Dukung `DEEPSEEK_MODEL=deepseek-flash` sebagai fallback bersama override lama
`DEEPSEEK_CHAT_MODEL` dan `DEEPSEEK_VISION_MODEL`; verifikasi implementasinya.

Tidak ada server port 3101 atau webhook `/whatsapp`; `/whatsapp` hanya UI.
`after()` bukan durable worker atau antrean tahan restart. Server dihentikan
atau redeploy sebelum selesai dapat menghilangkan pemrosesan setelah Twilio
menerima respons sukses. Untuk demo, biarkan server hidup dan kirim ulang
pesan baru jika tidak ada balasan; jangan menjanjikan retry otomatis Twilio
untuk respons yang sudah sukses. Ketahanan produksi di luar pekerjaan ini.

Audio dikirim ke Groq, transkrip dan foto ke DeepSeek, pesan ke Twilio.
Jelaskan persetujuan peserta, pemrosesan pihak ketiga, biaya, kuota dan
retensi penyedia. Tidak ada rahasia nyata di dokumentasi atau log.
Panel simulasi tetap jalur lokal, bukan bukti pengiriman provider nyata.
